Rules

1

Rotate purple and teal. Alternate them card to card and section to section. Never let a page or row go all one color.

2

Base fills, light text. Filled shapes use the base color; text and outlines use the light tint, so they read brighter than the fills.

3

Dark text on color. Purple, teal, and lime buttons and stickers always use #0C0C0C text, never white.

4

Teal sits lighter on purpose. Saturated purple looks brighter than it measures, so this pair reads as equal. Keep that balance if either shifts.

5

Lime is the call to action. Use it for "go here" links, stickers, and success, sparingly, so it keeps its pop.

6

Stickers mean different things. Solid lime, tilted left = status. Black with a lime outline, tilted right = a count.
